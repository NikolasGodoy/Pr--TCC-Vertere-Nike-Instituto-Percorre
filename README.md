# 👟 Projeto Pré-TCC - Réplica E-commerce Nike

Bem-vindo ao repositório do projeto de conclusão (Pré-TCC) do curso de Desenvolvimento Web do Instituto Percorre. 

Este projeto foi desenvolvido pela **Vertera**, uma consultoria focada em estratégia e transformação digital, com o objetivo de recriar a interface (Front-End) de páginas selecionadas do e-commerce da Nike, aplicando conceitos avançados de estruturação e design responsivo.

---

## 💻 Tecnologias Utilizadas

O projeto foi construído estritamente com tecnologias base do Front-End, respeitando requisitos técnicos desafiadores (sem uso de frameworks, JavaScript, CSS Grid ou Media Queries):

*   **HTML5:** Estruturação semântica de todas as páginas (`<header>`, `<main>`, `<section>`, `<aside>`, `<footer>`).
*   **CSS3:** Estilização completa do layout.
    *   Uso de **Flexbox** para alinhamentos em barras de navegação e eixos principais.
    *   Uso estratégico da propriedade `display: inline-block` aplicada a larguras em porcentagem (`%`) para simular a construção de *grids* de produtos flexíveis.
    *   Implementação de um Carrossel Hero (Slider) 100% funcional usando apenas CSS (`:target` e `position: absolute`).

---

## ⚙️ Funcionalidades e Páginas

O projeto contempla a recriação fiel do layout das seguintes páginas:

1.  **Página Inicial (Home/Index):** Banner rotativo em CSS, navegação e vitrine da linha SNKRS.
2.  **Páginas de Produto (E-commerce):** Estrutura completa de galeria de fotos, seleção de tamanhos e CTA de conversão.
    *   Tênis Nike Air Force 1
    *   Tênis Nike Dunk Low Women's
    *   Tênis Nike Air Max Plus TN
    *   Camisa Brasil Nike I 2026/27 (Alegria que Apavora)
    *   Camisa Brasil Jordan II 2026/27 (Joga Sinistro)
3.  **Rodapé Híbrido:** Uma estrutura de footer customizada contendo as informações legais simuladas da Nike à esquerda, e a assinatura técnica de desenvolvimento da Vertera à direita.
